Lesson 2.6: The Quadratic Formula

Learning goals

  • I can recall the quadratic formula.
  • I can recall the discriminant.
  • I can use the quadratic formula to solve a quadratic equation.
  • I can use the discriminant to determine the number and type of solutions a quadratic equation has.

Learning goals

Read the four goals aloud. Tell students the rhythm for today: notes and practice, then a game, with a check for understanding at the end. Students keep their guided notes handy for the fill-in blanks. Everything on the gold slides is a computer game.

The quadratic formula

x =

−b ± √(b² − 4ac)

2a

Use a, b, and c from the standard form, ax² + bx + c = 0.

Always make sure one side of your equation is equal to zero.

It gives the zeros (solutions) of a quadratic function.

Practice

Students find D for each and name the number and type of zeros. About 3 to 4 minutes. Look-fors: (−1)² written as −1 in G (b = −1, so b² = 1); the sign of −4ac in H when c is negative (it becomes +384); and F, where D = 0 gets mistaken for 'no solutions'.

Discriminant answers

DNumber and type of zeros
F144 − 144 = 01 real zero (x = −6)
G1 − 24 = −232 complex zeros

Practice

F: x² + 12x + 36 = (x + 6)², one repeated zero at -6. G: b = -1 so b² = 1, and -4(1)(6) = -24, so D = -23 (complex). H: 4x² − 4x − 24: a = 4, b = -4, c = -24, D = 16 − 4(4)(−24) = 16 + 384 = 400. √400 = 20, so x = (4 ± 20)/8 = 3 or -2. Quick check that H is correct: 4(9) − 12 − 24 = 0.

vertex: (1, −2)

no x-intercepts

Connect to the graph

D = 2² − 4(−1)(−3) = 4 − 12 = −8. √−8 = 2i√2, so x = (−2 ± 2i√2)/(−2) = 1 ∓ i√2, which is 1 ± i√2. The graph has no x-intercepts, and the complex solutions are not points on this graph. The vertex is at x = −b/2a = 1, y = −1 + 2 − 3 = −2.

GUIDE FOR READING RESPONSES. Q1: B = one repeated solution recognized. A = reads ± as always giving two answers; next step: solve with the formula and notice both answers equal 1. C = squared −6 as −36; next step: write (−6)(−6) in full and recompute D. D = treats a zero discriminant as nothing; next step: substitute x = 1 into the equation to show it works. Q2: C = reads sign of a and D together. A = reasons from the picture without computing D; next step: find D and the vertex (1, −4). B = overlooks the negative a; next step: plug in x = 1 for the vertex height. D = places complex solutions on the real x-axis; next step: ask whether 1 + 2i is a point on the x-axis and revisit the three-case table. Q3: A = full process. B = used b instead of −b; next step: line up a, b, c with signs. C = denominator 2 instead of 2a; next step: circle 2a before simplifying. D = stops once D < 0; next step: finish with √−23 = i√23. SORTING: Got it = 3 of 3, or Q3 correct with clean work. Almost there = one sign or denominator slip (Q3 B or C, Q1 C). Needs re-teaching = misreads D = 0 or places complex solutions on the graph (Q1 A or D, Q2 D, or Q3 D): revisit the three-case table and Game 3 before the next lesson.

Takeaways, then homework

D = b² − 4ac decides the number and type of solutions before you solve.

Real solutions are x-intercepts. Complex solutions are not points on the graph.

Before you solve, set one side equal to zero and find a, b, and c with their signs.

Homework time: about 30 minutes. Use D to check your work as you go.

Wrap

WRAP (1 min). Ask students to say one takeaway to a neighbor. Hand out or point to the homework. Remind them to compute D first: it tells them what answer to expect, which makes errors easy to catch. The games stay open at the link if students want extra practice.
